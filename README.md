# EVBikes — Electric bike instrument cluster (Qt for MCUs / Qt Quick Ultralite)

Futuristic, safe, low-cost cluster for a daily-commute electric motorcycle. Wide 1280 × 480 layout.
Built for **Qt for MCUs 2.12 LTS** (Qt Quick Ultralite) on microcontroller boards, with a desktop simulator.

## What it does

- Speed with glow, AMP (power) and RPM segment bars, ride mode (Eco / Normal / Sport) with colour change
- Telltales: indicators, low/high beam, warning, ABS, battery, side stand
- Battery %, range, odometer / trip, battery temperature
- **Turn-by-turn navigation from the phone** (arrow, distance, road, ETA, lanes) — the same approach as TVS SmartXonnect and RE Tripper
- Calls (answer / reject), music control, notifications, clock sync
- Tyre pressure page and alerts, overheat "Slow down" alert, crash + SOS alert
- Ride summary (km, money saved, CO₂ saved), PIN lock, settings (theme, brightness, clock, demo)

## Quick start

```bash
# host tests (no Qt needed)
cmake -S . -B build/tests -DEVB_BUILD_HOST_TESTS=ON && cmake --build build/tests && ctest --test-dir build/tests
python3 tools/qul_lint.py qml

# desktop app, either kit works:
#  - "Qt for MCUs – Desktop" kit  -> real Qt Quick Ultralite build
#  - any Qt 6.5+ kit (e.g. Qt 6.8 for macOS) -> Qt 6 preview build from desktop/
```

Boot: splash → choose rider (← →) → **Enter** scans the finger (rider 3 "KEVIN" is not enrolled → "No access") → pre-ride check → ride.
Riding: ← → bike / map · ↑ speedometer style · Enter opens the menu · Esc back · **M = next demo scenario**

Menu: press **P** to park the demo bike first (the menu only opens at 5 km/h or less), then **Enter**.

Desktop preview: frameless window, drag the frame to move it, **Q** or **Ctrl/Cmd+Q** quits.

## Folder map

```
qml/        Main.qml + modules: backend (C++ interfaces), core, components, screens
src/        C++: core (pure, tested), backend (singletons, glue, simulator), platform, os
assets/     fonts, icons, turn arrows, images (generated by tools/generate_assets.py)
tests/      host unit tests + backend smoke test
tools/      qul_lint.py, generate_assets.py, phone_link_sim.py, dbc/evbike.dbc
mobile-bridge/  Android reference code (Kotlin)
desktop/    Qt 6 desktop build: Qul shims, generated QML bridge, ColorizedImage
legacy/     the original Qt 6 desktop template (not built)
```
